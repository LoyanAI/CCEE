# 重结晶

## 一、重结晶的核心原理（考点根基，需理解本质）
重结晶的本质是**利用“目标物质”与“杂质”在同一溶剂中溶解度随温度变化的差异，实现二者分离提纯**，核心逻辑分两类：
1. 目标物质：溶解度随温度升高显著增大（如苯甲酸、KNO₃），加热时能溶解在少量溶剂中，冷却后因溶解度骤降大量析出。
2. 杂质：分两种情况
   - 难溶性杂质：加热时也不溶于溶剂（如粗苯甲酸中的泥沙），可通过“趁热过滤”直接除去。
   - 易溶性杂质：冷却时仍能溶解在溶剂中（如粗KNO₃中的NaCl），待目标物质析出后，随母液（过滤后的剩余溶液）被除去。

**高考易错点**：需区分“重结晶”与“结晶”的差异——结晶是从溶液中获取固体的单一操作（如蒸发结晶、冷却结晶），重结晶是“溶解→过滤→结晶”的组合操作，核心目的是**提纯粗品**，而非单纯获取固体。


## 二、溶剂选择的关键标准（考点核心，直接决定实验成败）
溶剂是重结晶的“灵魂”，高考常以“判断某溶剂是否适合重结晶”或“选择最佳溶剂”为命题点，需掌握4条刚性标准，每条均需结合实例理解：

| 溶剂选择标准 | 具体解释（含易错点） | 实例/反例 |
|--------------|----------------------|-----------|
| 1. 溶解度匹配 | 加热时（高温）：能充分溶解目标物质（需少量溶剂）；冷却时（低温）：目标物质溶解度显著降低（能大量析出） | 适合：蒸馏水提纯苯甲酸（苯甲酸在热水中溶解度大，冷水中溶解度极小）；<br>不适合：蒸馏水提纯NaCl（NaCl溶解度随温度变化小，冷却后几乎不析出） |
| 2. 不反应原则 | 溶剂不能与目标物质、杂质发生化学反应（包括氧化、还原、酯化、水解等） | 适合：乙醇提纯萘（二者不反应）；<br>不适合：用NaOH溶液提纯苯甲酸（苯甲酸与NaOH反应生成苯甲酸钠，失去目标物质） |
| 3. 杂质溶解度差异 | 杂质需满足“二选一”：<br>① 高温时不溶于溶剂（如泥沙），可趁热过滤除去；<br>② 低温时仍易溶于溶剂（如NaCl），随母液除去 | 适合：蒸馏水提纯粗KNO₃（杂质NaCl低温时仍溶于水，随母液除去）；<br>不适合：用CCl₄提纯粗碘（杂质NaCl不溶于CCl₄，但碘易升华，更适合升华操作，而非重结晶） |
| 4. 易分离性 | 溶剂需易与目标物质分离（如低沸点、易挥发），不残留于最终产品中 | 适合：乙醇提纯水杨酸（乙醇沸点78℃，低温烘干即可除去）；<br>不适合：用甘油提纯苯甲酸（甘油沸点290℃，难挥发，易残留于产品中） |

**高考延伸考点**：溶剂用量的控制——溶解粗品时，溶剂需“刚好溶解+少量过量（10%-20%）”。  
- 不足：加热时溶剂挥发，未溶解的固体可能包含目标物质，导致产率降低；  
- 过量：冷却时目标物质溶解度仍较高，析出量减少，同样导致产率降低。


## 三、完整操作步骤与细节考点（考点重点，多以实验填空/简答形式考查）
重结晶的操作流程需按“粗品溶解→趁热过滤→冷却结晶→过滤洗涤→干燥称量”顺序进行，每个步骤的操作细节、仪器选择、目的均为高频考点，需逐环节拆解：

### 3.1 步骤1：粗品溶解（制备热的饱和溶液）
- **操作**：将粗品放入烧杯中，加入选定溶剂，搅拌下加热至微沸（或目标温度），直至粗品完全溶解，再补加10%-20%的溶剂。  
- **仪器**：烧杯、玻璃棒（搅拌，加速溶解+防止局部过热）、酒精灯（加热，若溶剂易燃，需用水浴加热，如乙醇作溶剂时）。  
- **高考易错点**：  
  1. 加热方式：溶剂沸点低（如乙醚，沸点34.6℃）或易燃（如乙醇），必须用**水浴加热**，禁止直接酒精灯加热（防火灾）；  
  2. 固体未溶完的处理：先补加溶剂，若仍未溶，说明是难溶性杂质（如泥沙），无需继续加溶剂，后续通过趁热过滤除去。

### 3.2 步骤2：趁热过滤（除去难溶性杂质，防目标物质析出）
- **核心目的**：过滤掉高温下不溶于溶剂的杂质（如泥沙），同时避免目标物质因温度降低提前析出，混入杂质。  
- **操作细节**（高考高频填空点）：  
  1. 仪器预热：过滤前需将漏斗（必须用**短颈漏斗**，长颈漏斗残留液多，易冷却析出）、烧杯用热溶剂冲洗2-3次，或放入热水浴中预热；  
  2. 过滤速度：若过滤速度慢，可采用**减压过滤（抽滤）** ——用布氏漏斗、抽滤瓶、真空泵，加速过滤，同时减少溶液与空气的接触时间，降低温度下降幅度；  
  3. 承接容器：承接滤液的烧杯需加盖（或用表面皿），防溶剂挥发导致滤液浓度升高，提前析出晶体。  
- **高考易错仪器**：区分“趁热过滤”与“普通过滤”的仪器——普通过滤用长颈漏斗，趁热过滤用短颈漏斗（或布氏漏斗），若用长颈漏斗，残留的滤液会在长颈中冷却，析出的晶体堵塞漏斗，导致过滤失败。

### 3.3 步骤3：冷却结晶（使目标物质析出）
- **操作**：将趁热过滤后的滤液放入冷水浴（或冰水浴，根据需要）中，缓慢冷却，静置至晶体完全析出（避免搅拌，除非需要获取细小晶体）。  
- **高考考点**：冷却速度对晶体的影响——  
  1. 慢冷（如自然冷却）：晶体生长缓慢，颗粒大，纯度高（杂质不易包裹在晶体内部）；  
  2. 快冷（如冰水浴+搅拌）：晶体颗粒小，纯度稍低（易包裹母液，带入杂质），但析出速度快。  
- **易错点**：若滤液冷却后无晶体析出，可采用“诱导结晶”方法——① 用玻璃棒摩擦烧杯内壁（破坏过饱和状态）；② 加入少量目标物质的纯晶体（晶种）。

### 3.4 步骤4：过滤与洗涤（分离晶体与母液，除去表面杂质）
- **过滤**：用普通漏斗（或布氏漏斗）过滤，分离晶体与母液（母液中含易溶性杂质，需丢弃）。  
- **洗涤**（高考核心简答点，需说明“洗涤液选择”“洗涤操作”“洗涤干净的检验”）：  
  1. 洗涤液选择（需结合目标物质溶解度）：  
     - 若目标物质溶解度随温度变化大（如KNO₃）：用**冷水洗涤**——减少目标物质因溶解导致的损失；  
     - 若目标物质易溶于水（如苯甲酸）：用**乙醇洗涤**——① 乙醇与水互溶，能洗去表面母液；② 乙醇易挥发，后续干燥方便；③ 苯甲酸在乙醇中溶解度低，损失少；  
     - 若目标物质易溶于有机溶剂：用“该有机溶剂的稀溶液”或“冷的有机溶剂”洗涤。  
  2. 洗涤操作：向漏斗中的晶体加少量洗涤液，至刚好浸没晶体，静置待洗涤液自然流下，重复2-3次（不可用玻璃棒搅拌晶体，防晶体破碎，导致洗涤不充分）。  
  3. 洗涤干净的检验（高考高频实验设计点）：  
     - 原理：检验洗涤液中是否含“母液中的特征杂质离子”，若不含，则洗涤干净；  
     - 实例：重结晶提纯NaCl（粗品含BaCl₂杂质）——取最后一次洗涤液，滴加稀H₂SO₄，若无白色沉淀（BaSO₄）生成，则说明洗涤干净；  
     - 操作规范：需注明“取最后一次洗涤液”，否则步骤无效。

### 3.5 步骤5：干燥与称量（获取纯净产品，计算产率）
- **干燥方式**（根据晶体稳定性选择）：  
  1. 低温烘干：适用于受热易分解或易失去结晶水的晶体（如CuSO₄·5H₂O，需在50-60℃烘箱中烘干，高温会失去结晶水变为CuSO₄）；  
  2. 真空干燥：适用于高温下易氧化的晶体（如FeSO₄·7H₂O，真空环境防氧化）；  
  3. 自然晾干：适用于稳定性高、不易潮解的晶体（如NaCl）。  
- **高考考点**：干燥程度的判断——采用“恒重法”：将晶体烘干后称量质量，再继续烘干10-15分钟，再次称量，若两次质量差≤0.1g（或0.001g，根据精度要求），则说明已干燥完全（避免因未干燥导致产品质量偏高，产率计算误差）。  
- **产率计算**：产率=（实际得到的纯晶体质量 / 理论上粗品中目标物质的质量）×100%（高考需注意：若粗品中目标物质质量未知，可按“粗品质量×纯度”计算理论值）。


## 四、误差分析与异常情况处理（考点难点，多以实验探究形式考查）
重结晶实验的误差主要体现在“产率偏低”和“纯度偏低”两类，需明确每类误差的具体原因及对应操作失误：

### 4.1 产率偏低的原因（高考常考“分析产率低的可能因素”）
1. 溶剂过量：冷却时目标物质溶解度仍较高，析出量减少；  
2. 趁热过滤时目标物质析出：仪器未预热，或过滤速度太慢，导致滤液温度下降，目标物质在漏斗中析出，随杂质被丢弃；  
3. 洗涤时溶解损失过多：洗涤液选择不当（如用热水洗涤KNO₃晶体），或洗涤次数过多；  
4. 冷却不充分：滤液未冷却至足够温度，目标物质未完全析出；  
5. 晶体转移时损失：过滤后晶体残留在漏斗、烧杯壁上，未完全转移。

### 4.2 纯度偏低的原因（高考常考“分析产品不纯的原因”）
1. 趁热过滤不彻底：难溶性杂质未完全滤除，混入后续析出的晶体中；  
2. 冷却结晶时杂质共沉淀：杂质与目标物质的溶解度随温度变化趋势相似，冷却时同时析出（如粗KNO₃中含大量NaCl，若冷却过快，NaCl会随KNO₃一起析出）；  
3. 洗涤不彻底：晶体表面残留母液（含易溶性杂质），未洗净；  
4. 溶剂选择错误：溶剂与目标物质发生反应，生成新杂质（如用盐酸作溶剂提纯Na₂CO₃，生成NaCl杂质）。


## 五、重结晶与其他操作的关联考点（高考综合题常考）
1. 与“趁热过滤”的关联：重结晶中的“趁热过滤”是核心步骤，需与“固液分离”中的趁热过滤区分——前者是为了“除杂质+保目标”，后者可能仅为“保目标”（如分离KNO₃与NaCl时，趁热过滤除去NaCl，保留KNO₃滤液）；  
2. 与“减压过滤”的关联：重结晶中两次过滤（趁热过滤、晶体过滤）均可采用减压过滤，目的是“加速过滤+防冷却析出”（趁热过滤时）或“快速分离晶体与母液”（晶体过滤时）；  
3. 与“多次重结晶”的关联：若一次重结晶后产品纯度仍不达标，可进行多次重结晶——每次重结晶都会提高纯度，但会降低产率（每次都有溶解损失），高考常考“纯度与产率的平衡”（如“为何不进行5次重结晶？”答：多次重结晶会导致目标物质溶解损失过多，产率过低，性价比低）。


## 六、高考高频考法与真题导向（提升应试能力）
1. 选择题：判断溶剂是否适合重结晶（如2020年江苏卷：判断“用苯提纯硝基苯”是否可行，需结合“二者互溶，且硝基苯在苯中溶解度随温度变化小”判断不可行）；  
2. 填空题：填写重结晶的操作步骤（如“粗品溶解后下一步操作是___”，答案为“趁热过滤”）或仪器名称（如“趁热过滤需用到的玻璃仪器有___”，答案为“烧杯、短颈漏斗、玻璃棒”）；  
3. 实验题：分析误差原因（如2021年全国乙卷：重结晶提纯苯甲酸后产率偏低，原因可能是___，答案为“溶剂过量”或“趁热过滤时苯甲酸析出”）；设计洗涤干净的检验方案（如“检验重结晶提纯后的Na₂SO₄晶体是否洗净，需检验的离子是___，试剂是___”，答案为“Cl⁻，稀HNO₃和AgNO₃溶液”）。
