# 废水处理
### 一、废水污染类型与核心污染物判断（基础考点）
判断污染类型是选择处理方法的前提，需结合工业背景和流程产物精准识别。
1. **酸碱污染**
    - 来源：化工、电镀、制药等工艺排放的酸性废水（含H⁺，如硫酸、盐酸废水）或碱性废水（含OH⁻，如氢氧化钠、碳酸钠废水）。
    - 判断依据：流程中若有酸浸、碱溶步骤，或产物为酸碱类物质，末端易产生此类废水；题目常直接标注废水pH（如pH<2为强酸性，pH>11为强碱性）。
2. **重金属离子污染**
    - 核心污染物：常见有Cu²⁺、Pb²⁺、Hg²⁺、Cr³⁺、Ag⁺、Cd²⁺等。
    - 来源：电镀（如镀铜废水含Cu²⁺）、冶炼（如炼铅废水含Pb²⁺）、电池生产（如含Hg²⁺、Cd²⁺）等工艺。
    - 判断依据：流程中涉及金属矿开采、金属离子分离提纯时，废水易残留未除尽的重金属离子；题目可能给出离子检测结果（如“废水含Cr³⁺”）。
3. **无机非金属离子污染**
    - 常见污染物：含氰根离子（CN⁻，剧毒）、氟离子（F⁻）、亚硫酸根离子（SO₃²⁻）、亚硝酸根离子（NO₂⁻）等。
    - 来源：电镀（氰化物电镀液产生CN⁻废水）、磷肥生产（含F⁻废水）、印染（含SO₃²⁻废水）等。
    - 关键特性：CN⁻剧毒，需优先处理；F⁻易与Ca²⁺结合生成难溶物CaF₂。
4. **有机污染物污染**
    - 常见类型：含酚类（如苯酚）、醛类（如甲醛）、苯系物、染料（如印染废水）等。
    - 来源：印染、制药、煤化工、石油化工等工艺。
    - 判断难点：题目常以“有机废水”“含酚废水”等直接表述，需结合工艺中是否使用有机试剂（如萃取剂、有机催化剂）判断。


### 二、废水处理核心方法与原理（高频考点）
每种处理方法对应特定污染类型，需掌握原理、适用场景及反应本质，尤其关注化学法的反应方程式书写。

#### （一）物理处理法（预处理为主，常与化学法配合）
1. **过滤法**
    - 原理：利用滤纸、滤膜或石英砂等过滤介质，分离废水中的悬浮固体（如泥沙、不溶性杂质、化学沉淀生成的固体）。
    - 适用场景：废水含明显浑浊物，或化学沉淀后分离沉淀与上清液（如沉淀法处理重金属离子后，过滤去除Cu(OH)₂、PbCO₃等沉淀）。
    - 考点：判断过滤的位置（通常在沉淀反应后、后续处理前）；区分“过滤”与“渗析”（后者用于分离胶体与溶液，废水处理中极少用）。
2. **沉降法（重力沉降/离心沉降）**
    - 原理：利用悬浮颗粒的重力作用，使其自然沉降（或通过离心加速沉降），与水分离。
    - 辅助手段：常加入絮凝剂（如明矾KAl(SO₄)₂·12H₂O、聚合氯化铝PAC），使细小悬浮颗粒聚集形成大颗粒，加速沉降。
    - 适用场景：废水含密度较大的悬浮颗粒（如冶炼废水含金属碎屑），或胶体状杂质（如印染废水含染料胶体）。
3. **萃取法**
    - 原理：利用溶质（如废水中的有机污染物、某些金属离子）在两种互不相溶的溶剂中溶解度的差异，将溶质从水中转移到萃取剂中。
    - 适用场景：处理含难降解有机污染物（如酚类）或低浓度重金属离子（如萃取回收废水中的Cu²⁺、Ni²⁺）的废水。
    - 关键考点：萃取剂的选择（需与水互不相溶、溶质在其中溶解度远大于在水中、易与溶质分离）；萃取后需通过反萃取回收溶质和萃取剂（实现循环利用）。

#### （二）化学处理法（核心考点，占比最高）
1. **中和法（处理酸碱废水）**
    - 原理：利用酸与碱的中和反应（H⁺ + OH⁻ = H₂O），将废水pH调节至中性（通常pH 6-9，符合排放标准）。
    - 分类及适用场景：
        - 酸性废水处理：加入碱性试剂，如熟石灰（Ca(OH)₂，成本低、来源广）、氢氧化钠（NaOH，强碱性，中和速度快，适用于高浓度酸性废水）、碳酸钠（Na₂CO₃）。例：用Ca(OH)₂处理含H₂SO₄的废水，反应方程式为Ca(OH)₂ + H₂SO₄ = CaSO₄↓ + 2H₂O（CaSO₄微溶，需过滤去除）。
        - 碱性废水处理：加入酸性试剂，如稀硫酸（H₂SO₄，避免引入杂质离子）、盐酸（HCl）、二氧化碳（CO₂，成本低，适用于低浓度碱性废水）。例：用CO₂处理含NaOH的废水，反应方程式为2NaOH + CO₂ = Na₂CO₃ + H₂O（若CO₂过量，生成NaHCO₃）。
    - 高频考点：中和试剂的选择（优先考虑成本、是否引入新杂质、产物是否易处理）；中和反应方程式书写（需标注沉淀符号，如生成CaSO₄、Mg(OH)₂等）。
2. **沉淀法（处理重金属离子、F⁻等）**
    - 原理：向废水中加入沉淀剂，使污染物离子与沉淀剂离子结合生成难溶电解质（溶度积Ksp极小），通过过滤分离。
    - 沉淀剂选择与对应反应（核心）：
        - 氢氧化物沉淀剂：加入NaOH、Ca(OH)₂等，调节pH使重金属离子生成氢氧化物沉淀。例：处理含Cu²⁺的废水，Cu²⁺ + 2OH⁻ = Cu(OH)₂↓（需控制pH，避免OH⁻过量导致两性氢氧化物溶解，如Al(OH)₃溶于过量NaOH生成AlO₂⁻）。
        - 碳酸盐沉淀剂：加入Na₂CO₃、CaCO₃等，生成碳酸盐沉淀。例：处理含Pb²⁺的废水，Pb²⁺ + CO₃²⁻ = PbCO₃↓（PbCO₃难溶于水，可回收或无害化处理）。
        - 硫化物沉淀剂：加入Na₂S、H₂S等（需在酸性或碱性条件下控制用量，避免生成有毒H₂S气体），生成硫化物沉淀（Ksp远小于氢氧化物，适用于低浓度重金属离子处理）。例：处理含Hg²⁺的废水，Hg²⁺ + S²⁻ = HgS↓（HgS是Ksp最小的硫化物之一，处理彻底）。
        - 氟化物沉淀剂：处理含F⁻的废水，加入CaCl₂、Ca(OH)₂，生成CaF₂沉淀（CaF₂的Ksp=2.7×10⁻¹¹，难溶于水），反应方程式为Ca²⁺ + 2F⁻ = CaF₂↓。
    - 高频考点：沉淀剂的选择（根据污染物离子种类和Ksp数据）；pH控制对沉淀的影响（如Fe³⁺需在pH 3-4时完全沉淀为Fe(OH)₃，pH过高会生成FeO₂⁻）；沉淀的后续处理（回收有用金属，如从Cu(OH)₂沉淀中提取CuO）。
3. **氧化还原法（处理CN⁻、SO₃²⁻、NO₂⁻、有毒金属离子等）**
    - 原理：利用氧化还原反应，将废水中的有毒、还原性或氧化性污染物转化为无毒、稳定的物质（如将CN⁻氧化为CO₃²⁻和N₂，将Cr₂O₇²⁻（有毒）还原为Cr³⁺（毒性降低，可通过沉淀法去除））。
    - 常见类型及应用：
        - 氧化法（用氧化剂氧化污染物）：
            - 处理含CN⁻的废水：常用氧化剂为Cl₂（在碱性条件下，避免生成有毒HCN气体），反应方程式为2CN⁻ + 5Cl₂ + 8OH⁻ = 2CO₃²⁻ + N₂↑ + 10Cl⁻ + 4H₂O（核心反应，需熟记）。
            - 处理含SO₃²⁻、NO₂⁻的废水：加入H₂O₂、O₂、ClO⁻等氧化剂，将SO₃²⁻氧化为SO₄²⁻，NO₂⁻氧化为NO₃⁻（毒性降低，且SO₄²⁻、NO₃⁻易与其他离子分离）。
            - 处理含低价重金属离子的废水：如将Fe²⁺氧化为Fe³⁺（更易生成Fe(OH)₃沉淀），用H₂O₂氧化：2Fe²⁺ + H₂O₂ + 2H⁺ = 2Fe³⁺ + 2H₂O。
        - 还原法（用还原剂还原污染物）：
            - 处理含高价重金属离子的废水：如处理含Cr₂O₇²⁻（六价铬，剧毒）的电镀废水，加入FeSO₄、Na₂SO₃等还原剂，在酸性条件下将Cr₂O₇²⁻还原为Cr³⁺，反应方程式为Cr₂O₇²⁻ + 6Fe²⁺ + 14H⁺ = 2Cr³⁺ + 6Fe³⁺ + 7H₂O（还原后需调节pH使Cr³⁺生成Cr(OH)₃沉淀）。
            - 处理含Hg²⁺的废水：加入铁粉（置换法，属于还原法），Fe + Hg²⁺ = Fe²⁺ + Hg↓（Hg可回收，Fe²⁺后续用沉淀法处理）。
    - 高频考点：氧化还原反应方程式的书写（需结合酸碱条件，配平电荷和原子）；氧化剂/还原剂的选择（需考虑氧化性/还原性强弱、是否引入新杂质、成本）；反应条件控制（如碱性条件下氧化CN⁻，酸性条件下还原Cr₂O₇²⁻）。
4. **混凝法（处理胶体或细小悬浮颗粒）**
    - 原理：向废水中加入混凝剂，混凝剂在水中电离或水解生成胶体（如Al³⁺水解生成Al(OH)₃胶体），胶体具有吸附性，可吸附废水中的细小悬浮颗粒和胶体状污染物，形成大的絮状物（矾花），通过沉降或过滤分离。
    - 常用混凝剂：明矾（KAl(SO₄)₂·12H₂O，Al³⁺水解生成Al(OH)₃胶体）、聚合氯化铝（PAC，效果优于明矾，适用pH范围广）、硫酸亚铁（FeSO₄，Fe²⁺需先氧化为Fe³⁺，再水解生成Fe(OH)₃胶体）。
    - 适用场景：印染废水（含染料胶体）、造纸废水（含纤维细小颗粒）、生活污水（含悬浮物）。
    - 考点：混凝剂的作用原理（水解生成胶体，吸附杂质）；与沉淀法的区别（混凝法针对胶体和细小颗粒，沉淀法针对离子型污染物）。

#### （三）生物处理法（侧重原理和适用场景，难度较低）
1. **原理**：利用微生物（如细菌、真菌、藻类）的代谢作用，将废水中的有机污染物（如酚类、糖类、染料）分解为无害的无机物（如CO₂、H₂O、NH₃）或转化为自身营养物质，实现废水净化。
2. **常见类型**：
    - 好氧生物处理：在有氧条件下，好氧微生物分解有机污染物（如活性污泥法、生物膜法），适用于高浓度有机废水（如印染、食品加工废水）。
    - 厌氧生物处理：在无氧条件下，厌氧微生物分解有机污染物（如甲烷发酵法），适用于高浓度有机废水（如酒厂、化工厂废水），同时可产生沼气（CH₄），实现资源回收。
3. **适用场景**：主要处理有机污染物废水，不适用于含剧毒物质（如CN⁻、重金属离子）的废水（剧毒物质会杀死微生物）。
4. **考点**：生物处理法的适用范围（有机废水，无剧毒）；与化学法的区别（利用微生物代谢，绿色环保，成本低，但处理周期长）。


### 三、废水处理流程设计与优化（综合应用考点）
需结合污染类型、处理方法的特点，设计合理流程，并判断流程的合理性与优化方向。
1. **流程设计原则**
    - 预处理优先：先通过物理法（过滤、沉降）去除悬浮颗粒，避免后续化学试剂被杂质消耗，或堵塞设备（如离子交换柱）。
    - 分步处理：若废水含多种污染物，需按“先易后难、先毒后常”的顺序处理。例：含CN⁻和Cu²⁺的废水，先通过氧化法处理CN⁻（剧毒，优先去除），再通过沉淀法处理Cu²⁺。
    - 资源回收：处理过程中若产生可利用物质（如从沉淀中提取金属、从有机废水处理中产生沼气），需设计回收环节，符合“绿色化学”理念。
2. **流程优化分析**
    - 试剂用量优化：判断是否存在试剂过量导致新污染（如过量NaOH会使废水呈强碱性，需后续中和），或用量不足导致处理不彻底（如沉淀剂不足，重金属离子未完全沉淀）。
    - 循环利用：分析处理过程中产生的中间产物是否可循环（如过滤后的滤液若含未反应的沉淀剂，可返回前序环节继续使用），降低成本，减少废弃物。
    - 能耗与成本：对比不同处理方法的能耗（如生物处理法能耗低于化学氧化法）和成本（如用Ca(OH)₂中和酸性废水比用NaOH成本低），选择更经济的方案。


### 四、废水处理效果判断与检测（易错考点）
处理后废水需达到排放标准，需掌握关键检测指标和方法。
1. **pH检测**：用pH试纸或pH计检测，达标范围通常为6-9（中性或弱酸碱）。
2. **重金属离子检测**：
    - 定性检测：加入特定试剂，观察是否产生特征沉淀或颜色变化（如检测Cu²⁺，加入NaOH溶液，若不产生蓝色沉淀，说明Cu²⁺已除尽）。
    - 定量检测：通过原子吸收光谱法（题目常以“检测结果显示重金属离子浓度低于排放标准”表述，无需掌握具体方法，只需判断是否达标）。
3. **有机污染物检测**：通过检测化学需氧量（COD）或生化需氧量（BOD），COD/BOD值越低，说明有机污染物含量越少，处理效果越好。
4. **浊度检测**：观察废水是否澄清，或用浊度计检测，浊度越低，说明悬浮颗粒去除越彻底。
5. **考点**：根据检测结果判断处理是否达标（如“废水pH=7，加入Na₂S溶液无黑色沉淀，说明Cu²⁺已除尽”）；分析处理不彻底的原因（如试剂不足、pH控制不当、反应时间不够）。
